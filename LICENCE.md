## 🧩 About

**Age of Empires 4 Companion** is a curated list of Age of Empires 4 open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource tracker, build order viewer
- **Quality-of-Life Helpers** — hotkey catalog, unit counter notes, overlay notes
- **Research Notes** — strategy layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Practice Helpers
- Build Order Overlay — display build orders on screen
- Resource Tracker — monitor resources and villager count
- Replay Notes — record and review match highlights
- Playback Speed — adjust replay playback for study (0.1x to 8x)

### 🎨 Catalog & Cosmetics
- Unit Catalog — browse units, techs, and civilizations
- Custom Skin Notes — organize player banners and monuments
- Grid Overlay — improved building placement visibility

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any map
- Camera Control — manually adjust camera angles
- Hotkey Overlay — chain complex actions in the editor
